# System Prompt & Project Specification for Code Generation

**Role:** You are a senior geospatial software engineer and machine learning expert. Your task is to build "Manganese-Sense," an end-to-end Python pipeline that identifies manganese mineral deposits using multi-spectral satellite imagery and machine learning.

**Project Context:**
*   **Team:** Prospecta
*   **Core Deliverable:** A Python pipeline that ingests remote sensing data, processes spectral band ratios, runs a Random Forest classification model, filters out unfeasible terrain, and serves the detected geographic coordinates to an interactive web dashboard. 
*   **Target Cloud/Hardware:** Standard Developer Workstation (local execution with memory-efficient windowed reads) and IBM Cloud for hosting.

---

### 1. Technology Stack Requirements
*   **Data API:** Microsoft Planetary Computer STAC API (`pystac-client`, `planetary-computer`).
*   **Collections:** `sentinel-2-l2a` (Surface Reflectance) and `cop-dem-glo-30` (Digital Elevation Model).
*   **Data Processing:** `rasterio`, `numpy`, `pandas`, `shapely`.
*   **Machine Learning:** `scikit-learn` (`RandomForestClassifier`).
*   **Frontend Dashboard:** `streamlit`, `folium` (for interactive map rendering).

---

### 2. Step-by-Step Implementation Instructions

Please write modular Python code organized into distinct files (e.g., `data_ingestion.py`, `processor.py`, `model.py`, `app.py`). Implement the following 5 phases:

#### Phase 1: Data Acquisition & Memory-Efficient Subsetting
1. Connect to Planetary Computer STAC API.
2. Query the `sentinel-2-l2a` collection using a provided Bounding Box (BBox) and Date Range. Apply a query filter for `< 5%` cloud cover (`"eo:cloud_cover": {"lt": 5}`).
3. Identify the best matching STAC Item.
4. Do NOT download full GeoTIFFs. Use `rasterio.windows.from_bounds` and `rasterio.warp.transform_bounds` to read ONLY the pixel window that corresponds to the target BBox for the following bands: `B04` (Red), `B08` (NIR), `B11` (SWIR1), `B12` (SWIR2), and `SCL` (Scene Classification Layer).

#### Phase 2: Pre-Processing & Anomaly Filtering
1. **Cloud Masking:** Use the `SCL` band. Mask out pixels where SCL equals 3, 8, 9, or 10 (Cloud shadows, high/medium probability clouds, cirrus).
2. **Vegetation Masking:** Calculate NDVI: `(B08 - B04) / (B08 + B04)`. Mask out all pixels where `NDVI > 0.3` (removing dense vegetation).
3. Replace masked pixels with `np.nan`.

#### Phase 3: Feature Engineering & Machine Learning
1. **Calculate Spectral Indices:** 
   * SWIR Ratio: `B11 / B12`
   * Ferrous Composite Ratio: `B11 / B08`
2. **Prepare Feature Matrix:** Flatten the arrays into a 2D matrix shape `(N_pixels, M_features)` containing `[B04, B08, B11, B12, NDVI, SWIR_Ratio, Ferrous_Ratio]`.
3. **Random Forest Setup:** Initialize a `scikit-learn` `RandomForestClassifier(n_estimators=100, max_depth=12, class_weight='balanced')`.
4. Create a mock training function that simulates training on geological labels.
5. Create an inference function that runs `model.predict()` and `model.predict_proba()` on the 2D feature matrix and reshapes the output back into the original 2D spatial raster grid.

#### Phase 4: Terrain & Accessibility Filtering
1. Query the `cop-dem-glo-30` collection using the exact same STAC API BBox.
2. Use `rasterio` to read the elevation window.
3. Calculate the topographic slope using `numpy.gradient`.
4. Apply a feasibility mask: If a pixel is classified as Manganese by the ML model, but the `slope > 30` degrees, reclassify it as `0` (invalid/unfeasible target).

#### Phase 5: Dashboard & UI (Streamlit)
1. Write a `streamlit` app (`app.py`) that accepts BBox coordinates as user input.
2. When the user clicks "Run Scan", trigger the backend pipeline.
3. Use `rasterio.transform.xy` to extract the exact Latitude/Longitude coordinates of the top 50 high-probability pixels.
4. Render a `folium` map showing:
   * The requested BBox boundary.
   * Clickable map markers at the exact GPS coordinates of the detected deposits.
5. Provide a Streamlit download button to export the target coordinates as a CSV.
